# 邊緣停留與自適應分割

`dist/docking.js` 使用二元分割樹管理右側視窗；`dist/explorer-ui.js` 保留浮動工具拖曳／收合。搬移原 DOM 節點，不複製控制項。

- 沒有「停靠／浮動」文字按鈕。拖工具標題到右側任一內容視窗的上、下、左、右內緣（12px 內），穩定停留 650ms，提示從虛框變實框後放開，才建立對應方向的分割。
- 視窗中央、外側空隙、快速掠過皆不觸發。沿邊移動超過 10px 重新計時；離開、取消、失焦清除提示。
- 可以對新聞／Chat 或已分割的工具視窗繼續分割；不再固定右下。保留原本新聞／Chat 頁籤。
- 拖標題回圖中會移出分割區，其兄弟視窗自動補位。各分隔線可拖曳；方向鍵／Home 同樣能調大小。右側既有外邊界控制總寬度。
- `graphnews.toolDock` version 2 保存分割樹、順序與比例；還原時驗證合法工具 ID、唯一性、深度與新聞視窗。舊固定下方版面可遷移。浮動位置仍由原偏好保存。
- 收合圖示由 36px 放大為 72px、符號由 22px 放大為 44px。上方導覽空間保留；分割區工具不參與圖內碰撞避讓。
- 短分割視窗精簡曲線說明與讀數，讓時間曲線及 K 線優先可見；內容仍可捲動。MCP runtime 提供分割樹及邊緣／停留條件。

驗證：`tests/browser_price_dock.py` 真實滑鼠檢查中央／空隙／快速掠過不吸附、邊緣停留分割、上下左右配置、拖出補位、分隔調整、雙倍圖示與重新整理。`tests/browser_user_journeys.py` 覆蓋既有來源控制、2,400 節點及 WebGL 重試。

## 2026-11-03 拖出後補位修正

左右邊緣使用 row（垂直分隔線），上下邊緣使用 column（水平分隔線）。移除巢狀分割時，升上來的兄弟節點原有 flex 比例屬於已刪除的父節點，不能直接沿用。結構改變與調整比例後遞迴套用現存父節點 ratio，根視窗填滿空間；保留收合工具的最小空間。回歸先重現舊版「樹已正確但剩餘視窗比例錯誤」，再驗證 DOM 的實際 flex 與外層比例一致，含重新整理保存。

## 2026-11-06 窄視窗展開被碰撞邏輯撤銷

舊避讓找不到位置時會把正在展開的工具重新收合。當中間寬度不足以並排 660px 工具與 72px 圖示，高度也放不下時可穩定重現。現在使用者最近開啟／拖動的工具優先；其他工具收合並移到邊緣，展開工具按剩餘高度捲動，不再用自動收合撤銷點擊。背景 ResizeObserver 必須讓位給正在操作的工具；停靠時清除浮動高度上限。

`tests/browser_feedback.py` 在 1100px 視窗使用真實滑鼠事件驗證展開、邊界及不重疊；`tests/test_floating_panels.cjs` 保留拖曳／控制項排除檢查。

## 浮動視窗尺寸（2026-11-06）

`dist/floating-resize.js` 管理時間與來源工具的四邊／四角拖曳。展開預設時間 480×380、來源 430×320；受當下圖區可用尺寸限制，通常最小 280×180。標題固定，內容在自己的 body 捲動。尺寸與位置、收合狀態一同存於各自 `graphnews.timePanel/sourcePanel` 瀏覽器偏好，收合／展開／重新整理沿用；不宣稱跨設定檔保存。

調整大小使用把手的 pointer capture，事件不交給父層搬移或圖譜；失焦／取消回復本次起始幾何，放開保存。底部定位的面板在高度改變後需以實際新矩形補償位置，不能只更改 height。方向鍵每次 20px，Home 回預設尺寸。停靠後隱藏浮動把手，尺寸由分割樹管理；拖回圖中沿用浮動尺寸。

驗證：`tests/browser_floating_resize.py` 的隔離前端 fixture 用真實 CDP 拖曳檢查角／邊、內容捲動、取消、資料不變、收合／重載及停靠往返；HTTP 資產路由由 `browser_render_regressions.py` 與 `browser_live_merge.py` 驗證。
