# 股價與時間混合大小

2026-11-03：`news_atlas/price_lens.py`、`dist/price-lens.js`、`dist/time-lens.js`。

## 定義與顯示

只使用左側明確填入的 Massive ticker；不由搜尋關鍵字或新聞實體推測。美東時間發布於 09:30 前可用當天完整交易日，其他時間從下一交易日開始。基準為首個完整交易日收盤價 C0；N=1/3/5/7，平均報酬為其後 N 個有日線的交易日 `(Cj/C0-1)` 的算術平均。週末／假日按實際日線跳過；不插值。只用截至美東昨天資料，避免盤中價與 Basic 方案當日日線限制。無有效日線的日期不計入交易日，因此停牌／來源缺口會延後窗口；本版不另外推斷交易所日曆。

拆股調整價格，不含股息。這是事後價格表現，不是新聞因果或預測。

股價動能為上述 N 日平均報酬 delta，以同一股票已載入日線、所有有完整 N 日的基準交易日之絕對報酬 P95 作尺度；採 nearest-rank 分位數，不按新聞篇數重複加權。`z=clamp(delta/P95,-1,1)`，`股價倍率=2**(2*z)`，範圍 0.25–4 倍。全零尺度時 z=0、倍率=1；舊快照無日線時以去重基準日 observations 作備援。尺度按資料物件和 N 快取，資料範圍改變可改變尺度；拖曳或縮放不重估尺度。混合為 `(1-w)*時間倍率+w*股價倍率`，預設 w=0。沒有完整 N 日則保留原時間倍率，不把缺失當零收益。原時間滑桿、鐘形曲線與遠近補償繼續作用；大小開關控制整個大小功能。3D 與時間軸使用同一混合函式，不改 edges、roots 或物理距離。

## API、快取與保存

`POST /api/prices/lens` 接收 ticker、articles 的 id/published_at，以及選填 massive_key（只用於該次請求；否則用主機私有設定）。一次讀取日線後計算全部四種天數；滑桿不再請求網路。資料最多跨 400 天新聞；日線最多追加 32 曆日並裁切至美東昨天。

日線存於新聞 DB 旁 `.prices.sqlite3`，TTL 六小時、保留最近 64 個 ticker/日期區間；不存金鑰。載入按鈕會讀取或命中快取，並非強制繞過 TTL。設定保存在瀏覽器；明確保存圖譜快照會保存 `view.price_focus` 的混合比例、天數、ticker、截至日及每篇報酬。還原使用該份凍結證據，不偷偷更新價格，也不覆寫左側搜尋草稿。需要新證據時以目前明確 ticker 再載入。改 ticker 立即清除舊證據；過期非同步回覆以 epoch/abort 排除。新搜尋新增或日期不同的文章需重新載入；未命中者只用時間大小。

## 同次 UI 修正

選中新聞在右側詳情頂部加紅框與「目前選取新聞」標記，點選會把詳情捲到頂端。搜尋清單維持來源合併的順序，不代表與當前 root 的相似度排名。Chat 頁籤保持使用者選取，不強制跳回新聞。

語言錯誤原因是整個 Chat 面板被標成 `.raw`，加上 textarea 被翻譯 walker 排除。修正為只有使用者／模型內容保留 raw，UI 使用翻譯流程，placeholder/copy 另隨語言事件更新。不可翻譯原新聞或模型回答。

## 2026-11-03 K 線與共同時間軸

`dist/price-chart.js` 以 Massive 真實 o/h/l/c 畫日 K 線；只有收盤價的舊資料畫灰色點，不製造開高低。日線快取 key 升為 `split-adjusted-ohlc-v2`。快照新增 bars 白名單（最多 500 日、日期遞增、合法 OHLC）；舊快照仍可還原，重新載入股價後才有 K 線。

時間曲線、日期滑桿、股價圖共用日期範圍和同一個垂直虛線。歷史股價尾端超過新聞日期時，大小焦點區間延長到最後有價格的日期，避免剪掉新聞後 N 日；不更動新聞時間軸 cutoff 或新聞集合。點選新聞把焦點設為發布 UTC 日期，基準仍按完整美東交易日計算，圖上分別標出焦點與基準。拖日期滑桿或 K 線會解除該篇的精確發布時刻錨定，改以焦點日第一個有效交易日為基準。

彩色線不是傳統向後移動平均：第 j 點是基準之後第 1 至 j 個收盤價的累計平均，j≤N；最後一點對基準的報酬等於節點大小所用的 N 日平均報酬。資料未滿 N 日時可看到已發生的部分，但標示資料不足，不使用部分報酬縮放節點。N 日後價格遮罩，不猜未來。保留之前歷史 K 線作背景。

配色預設美股綠漲紅跌，可選台股紅漲綠跌，僅改視覺慣例，不切換資料市場。K 線顏色以收盤對開盤，平均線顏色以對基準的報酬，並顯示 ↑/↓ 與正負號。這是歷史日線，不是即時股價。價格來源仍由明確 Massive ticker 決定。

`tests/price-chart.test.cjs` 驗證累計平均、週末、缺資料與配色；`tests/browser_price_dock.py` 使用隔離 fixture 驗證真實 pointer 操作、日期同步、對齊與版面保存。真實 API 小範圍 AAPL OHLC 已驗證，但測試 fixture 不寫正式新聞 DB。

## 修正：自動顯示行情與來源市場配色

舊流程只在按「載入股價」或更改非零混合權重時發請求，因此有新聞與明確 ticker 仍可能空白。真實瀏覽器回歸曾得到 0 根 K 線；自動載入修正後，同一 AAPL 範例取得 250 個交易日。

現在新聞／明確 ticker 穩定 650ms 後自動請求；以文章 ID＋日期及 ticker 識別避免滑桿操作重抓。失敗不無限重試，錯誤／無代碼／無資料直接呈現在股價圖，手動載入仍可重試。舊快照無 OHLC 時以快照明確 ticker 作備援，不由關鍵字推測公司，也不覆寫搜尋草稿。

已移除配色選單。API 回傳實際資料來源的 market/currency，目前 Massive 股票日線端點為 US/USD，使用綠漲紅跌；不是按頁面語言、RSS 地區或股票字串猜市場。未接入台股行情，不能將台股 ticker 當成已支援。未來真正的 TW 提供者應帶市場 metadata 後才使用紅漲綠跌。

K 線加上收盤價線，滑鼠經過顯示日期及 OHLC 數字。短分割區優先顯示曲線與股價，避免資料已載入但圖表藏在說明下面。以上取代前版手動配色與純手動載入說明。

## 2026-11-03 動能貢獻與圖表互動

- 鐘形輪廓仍是時間塑形曲線；內部藍色／金色分別顯示該日實際時間／股價倍率貢獻。股價色塊比例為 `w*priceMultiplier / ((1-w)*timeMultiplier+w*priceMultiplier)`，不是直接複製輸入權重。游標讀數含日期、各成份占比、混合倍率、delta 和標準化 z。缺完整 N 日時時間占 100%。點選新聞當天採該新聞完整交易日基準。
- 圖內滑鼠十字線與 OHLC 讀數；滾輪以焦點日期為中心縮放，最少七曆日（完整範圍更短則用完整範圍）。雙擊還原。日期滑桿、鐘形曲線、股價圖共用顯示範圍；原節點大小、價格標準化及塑形計算仍用完整資料域。選新聞會重設縮放並定位日期。縮放為暫時 UI 狀態，不寫入快照；MCP runtime 可讀 viewport。
- N 日完整平均報酬大於零高亮上箭頭，小於零高亮下箭頭；零或缺資料不高亮。箭頭代表對基準的 N 日表現，K 線仍代表當日收盤對開盤。
- 回歸必須驗證縮放前後 time_focus 不變、三者日期軸一致；不能把畫面縮放誤當計算區間更新。
