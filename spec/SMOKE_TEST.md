# 空資料 smoke test

基準：2026-11-09，本機 `llm_wiki` 程式 `8285c09`。本輪按要求刪除全部專案 DB，包含舊備份；登入憑證保留。重新啟動後新聞 0、Wiki 目錄空、workspace 空；空 schema DB 可由服務自動建立。這是手動測試起點，不是已完成全流程驗收。

## 建議操作順序

1. 關閉舊分頁，以無痕視窗或新瀏覽器 profile 開啟 http://127.0.0.1:8765/。同 profile 的新視窗仍可能共用偏好；舊頁可能回存舊 workspace。確認空新聞、空 Wiki，沒有自動接續舊工作。
2. 填入 `交易所:股票代碼`，確認股票必填、關鍵字自動帶入且可編輯。自行選擇測試日期與來源後搜尋；這一步才開始建立新資料，不沿用歷史主機的固定股票或日期。
3. 新聞圖譜驗證旋轉／平移、點選星河、拖動保留選取、空白點擊取消；時間模組可移動／縮放且內容可捲動，K 線沒有紅綠色條溢出。切換 News／Wiki 後各自設定與視圖保留。
4. Wiki Graph 方法不需先手動點 root；選定 Wiki 日期並套用。模型工作由使用者明確開始，觀察排隊／執行／完成與錯誤狀態；整棵樹全部段落成功才計 coverage，動畫不是完成證據。
5. 分類選單、色條與觀點群清單應一致；尚待分類／未分類如實顯示，多標籤總數可大於群數。節點高亮時其他資料變暗，拖動不取消選取。
6. L2 研究由使用者輸入問題並啟動。L1 佔用模型時應顯示佔用股票；中央與側欄進度一致，完成可沿引用回讀 L1。切層、切股、重進後不能掛上舊回覆；讀取失敗應恢復既有結果，不能偷偷重送模型。
7. Chat 切英文後檢查連線提示、Wiki context；再測重新連線、重新整理與另一分頁。介面文案跟隨當前語言，原始證據語言不強改。調整左右欄與時間圖邊界，確認捲動與輸入框可用。
8. 建立資料後重新整理，確認持久狀態恢復。若要測 USB 匯入，依啟動時列出的 merge_data 範例及 [DATA_MERGE](DATA_MERGE.md) 操作，觀察目錄更新；匯入後就不再是空資料基準。
